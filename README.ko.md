# PeekSlide

[English](README.md) | 한국어

Figma나 PDF로 내보낸 슬라이드를 훑어보고, 클릭할 때마다 강조 표시를 보여 주며 발표할 수 있는 정적 사이트입니다. 주소: https://beaver-shop.cloud

## 기능

- 전체 슬라이드를 격자로 보거나 파트별로 나눠 봅니다.
- 슬라이드를 넘기면서 클릭마다 박스와 선으로 강조합니다. 페이지별로 Q&A, 링크, 영상도 붙일 수 있습니다.
- 발표 모드, 단축키, 라이트/다크 테마를 지원합니다.
- 관리자로 로그인하면 브라우저에서 강조 표시와 파트를 편집합니다.
- 프로젝트마다 비밀번호를 걸 수 있습니다.

## 구조

슬라이드는 PDF를 이미지로 변환해서 씁니다. 프로젝트는 `pages.json`이 든 폴더 하나이고, 빌드 단계에서 사이트가 읽는 데이터로 바뀝니다. 프런트엔드는 프레임워크 없이 JavaScript와 CSS로 작성했고 Vite로 빌드합니다.

사이트는 CloudFront 뒤의 S3에서 제공하고, 도메인은 Route 53과 ACM으로 연결했습니다. `main`에 push하면 GitHub Actions가 빌드와 검사를 거쳐 S3에 올리고 CloudFront 캐시를 무효화합니다. AWS에는 OIDC로 IAM 역할을 받아 접근하므로 액세스 키를 저장하지 않습니다.

브라우저에서 한 편집은 Lambda 함수 하나(함수 URL)로 보냅니다. Lambda는 관리자 비밀번호와 요청 내용을 검증한 뒤 GitHub API로 `pages.json`을 커밋합니다. 이 커밋이 같은 배포 워크플로를 실행하므로, 데이터 저장소는 Git 하나뿐이고 데이터베이스는 없습니다.

## 사용법

Node.js 22 이상이 필요합니다.

    npm install
    npm run dev

PDF로 새 프로젝트를 추가합니다. 변환, 커밋, push까지 하고 배포는 자동으로 진행됩니다.

    bash scripts/add.sh <이름> "<PDF 경로>"

프로젝트 제목을 바꿉니다.

    bash scripts/title.sh <이름> "<새 제목>"

단축키: 좌우 방향키나 Space로 이동, P 발표 모드, Q 노트, T 테마, Esc 종료.

## 한계

프로젝트 비밀번호는 브라우저에서 확인(SHA-256)합니다. 가볍게 막는 용도이고 실제 접근 제어는 아니며, 이미지 주소를 알면 바로 열 수 있습니다.

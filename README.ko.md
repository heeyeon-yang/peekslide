# PeekSlide

[English](README.md) | 한국어

PDF 슬라이드에 하이라이트, 플로우 같은 발표 효과를 넣어 발표할 수 있는 웹사이트입니다. PDF를 올리면 페이지마다 원하는 효과를 추가할 수 있습니다. 주소: https://beaver-shop.cloud

## 기능

- 전체 슬라이드를 파트별로 나눠 볼 수 있습니다.
- 슬라이드마다 넘김 효과(플로우, 하이라이트 등)를 추가할 수 있습니다. 페이지별로 Q&A, 링크, 영상도 붙일 수 있습니다.
- 발표 모드, 단축키, 라이트/다크 테마를 지원합니다.
- 관리자로 로그인하면 브라우저에서 효과와 파트를 편집할 수 있습니다.
- 프로젝트마다 비밀번호를 걸 수 있습니다.

## 구조

슬라이드는 PDF를 이미지로 변환해서 씁니다. 프로젝트는 `pages.json`이 든 폴더 하나이고, 빌드 단계에서 사이트가 읽는 데이터로 바뀝니다. 프런트엔드는 프레임워크 없이 JavaScript와 CSS로 작성했고 Vite로 빌드합니다.

사이트는 CloudFront 뒤의 S3에서 제공하고, 도메인은 Route 53과 ACM으로 연결했습니다. `main`에 push하면 GitHub Actions가 빌드와 검사를 거쳐 S3에 올리고 CloudFront 캐시를 무효화합니다. AWS에는 OIDC로 IAM 역할을 받아 접근하므로 액세스 키를 저장하지 않습니다.

브라우저에서 한 편집 내용은 Lambda 함수 하나(함수 URL)로 보냅니다. Lambda는 관리자 비밀번호와 요청 내용을 검증한 뒤 GitHub API로 `pages.json`을 커밋합니다. 이 커밋이 같은 배포 워크플로를 실행하므로, 데이터 저장소는 Git 하나뿐이고 데이터베이스는 없습니다.

## 사용법

Node.js 22 이상이 필요합니다.

    npm install
    npm run dev

PDF로 새 프로젝트를 추가합니다. 변환부터 커밋, push까지 실행하고, 이후 배포는 자동으로 진행됩니다.

    bash scripts/add.sh <이름> "<PDF 경로>"

프로젝트 제목을 바꿉니다.

    bash scripts/title.sh <이름> "<새 제목>"

단축키: 좌우 방향키나 Space로 이동, P 발표 모드, Q Q&A, T 테마, Esc 종료.
